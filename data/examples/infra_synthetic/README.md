# 合成六轴流程示例

本目录是人工构造的确定性数据，**不是实物采集，也不证明真实跳绳识别精度**。

- `imu_raw.csv`：775 个六轴样本，50 Hz；包含两个启动片段，首片段有 0.5 秒采样缺口。
- `session.json`：明确标记 synthetic 的源元信息。
- `ground_truth.json`：依据构造的正弦相位生成动作时刻与有效区间，不是算法输出生成的真值；为示例模板，不是已经绑定本地 capture_key 的标注版本。

可在工作台“数据”上传原始 CSV 与 session；若要自动绑定标注和数据集，直接点击“创建合成流程示例”。两条路径复用 `infra.demo.synthetic_fixture`，每次安装产生新批次，保留原始示例。

完整步骤见 [Infra 操作说明](../../../docs/INFRA.md)。
